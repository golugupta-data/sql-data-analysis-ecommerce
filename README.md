# SQL Data Analysis – E-commerce

## 📌 Project Overview

This project focuses on analyzing an e-commerce dataset using SQL.

## 🛠️ Tools Used

- MySQL
- SQL
- E-commerce Dataset

## 📊 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- HAVING
- LIMIT

## 🔍 Analysis Performed

- Total number of orders
- Total revenue
- Average order value
- Product-wise sales analysis
- Payment method analysis
- Order status analysis
- Top-performing products

## 📁 Project Files

- `Project_3_SQL_Data_Analysis.sql` – SQL queries used for analysis
- `README.md` – Project documentation

## 🎯 Objective

The objective of this project is to demonstrate fundamental SQL
data analysis and querying skills using an e-commerce dataset.
